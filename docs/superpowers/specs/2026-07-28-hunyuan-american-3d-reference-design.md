# 混元图生 3D 输入图设计

## 目标

以用户提供的图一为人物与构图基准，生成一张可直接上传混元进行图生 3D 的全新正面参考图。整体采用偏美式的半写实 3D 游戏角色美术，不复刻图三的建模瑕疵。

## 保留

- 图一的人物辨识度、浓眉、黑色蓬松卷发和冷静表情
- 正面平视的胸像构图
- 蓝色牛仔夹克和白色圆领上衣
- 完整头部、双耳及肩部轮廓

## 调整

- 中等偏深的暖棕肤色，避免苍白和粉白滤镜
- 更明显的眉骨、颧骨、鼻梁与方正下颌
- 美式动画与 3A 游戏角色之间的半写实比例
- 哑光 PBR 皮肤、低高光厚重黑发、电影感柔和棚拍光
- 深灰纯色背景，弱透视、对称、结构清晰，方便图生 3D

## 排除

- 蜡像、塑料、陶瓷或油亮皮肤
- 二次元大眼、尖下巴、幼态或过瘦脸
- 毛发穿入额头、眉毛或耳朵，材质串色、发丝粘连
- 歪头、侧脸、夸张表情、强景深、复杂背景、文字和贴纸

## 验收

- 第一眼仍能识别为图一中的同一角色
- 肤色明显比混元旧结果更暖、更深，但五官不过暗
- 下颌和面部体块更具美式角色感
- 发际线、眉毛、耳朵边界干净
- 可作为单张正面输入直接提交混元图生 3D
