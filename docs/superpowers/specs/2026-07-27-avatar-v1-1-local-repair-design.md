# 个人头像 V1.1 局部修复设计

日期：2026-07-27

## 目标

以第一版头像为唯一基础，保留其脸型、五官、卷发主体、服装、材质风格和身体比例，只修复眉毛、额头与双耳附近的发型穿模和颜色污染，并提高正面辨识清晰度。

第一版源文件保持不变。第二版及其重建发型不参与本次处理。

## 输入与输出

- Blender 源文件：`assets/avatar/blender/avatar-final.blend`
- 原版 GLB：`assets/avatar/model/avatar-final.glb`
- 参考正面：`assets/avatar/preview/avatar-final-front.png`
- 参考侧面：`assets/avatar/preview/avatar-final-side.png`
- 修复版 Blender：`assets/avatar/blender/avatar-v1.1-repaired.blend`
- 修复版 GLB：`xiaoyuan-avatar-intro3d-v1.1.glb`
- 验收预览：`assets/avatar/preview/v1.1-repaired/`

## 修复范围

### 眉毛与额头

- 删除或回退穿过眉毛、压住眉形的少量发丝面。
- 保留原眉形、眉间距、眉峰方向和表情。
- 必要时增加贴合皮肤表面的独立眉毛薄层，恢复左右眉毛的清晰边界。
- 清理眉毛周围和额头上的黑色、棕色污染，不改变眼睛、鼻子和脸型。

### 耳朵

- 仅清理遮挡耳朵轮廓的局部发丝。
- 在原耳朵位置修整外耳轮、耳甲和耳垂轮廓。
- 耳朵尺寸、位置和朝向以原版头部比例为准，不添加夸张的大耳结构。
- 修复发色污染，并保留自然的内耳阴影。

### 清晰度

- 保留原版主体贴图，不重新生成整张脸。
- 对面部、眉毛和衣领等关键区域做轻度锐化与对比度整理。
- 局部皮肤补色以相邻原始皮肤采样为准，不凭空生成新的皮肤纹理。
- GLB 内嵌无损 PNG 贴图；不使用会明显降低清晰度的有损纹理压缩。

## 明确不做

- 不重建整颗头。
- 不替换原版卷发。
- 不改变脸长、鼻子、嘴唇、眼睛、下颌或表情。
- 不改变牛仔外套和白色内搭。
- 不重新进行 AI 单图生模。
- 不沿用 V2 的头皮、发束、耳朵或脸部变形。
- 不删除原版或第二版文件。

## 实施策略

1. 从第一版 Blender 文件复制出 V1.1 工作副本。
2. 建立眉毛、左右耳朵和额头三个局部选择区域。
3. 先处理几何穿模，只删除能够明确判断为错误的局部发丝面。
4. 对耳廓进行小幅位置和法线整理；缺损时使用贴合原轮廓的局部补面。
5. 修复局部贴图污染，并保持原 UV 和原主体材质。
6. 生成正面、45°、左右侧面和发际线近景预览。
7. 导出 GLB，再从 GLB 重新导入空 Blender 场景进行回读验证。

## 验收标准

- 正面整体观感与第一版一致，不能出现第二版的发型或脸型。
- 左右眉毛轮廓可以独立辨认，眉毛前方没有明显穿出的发丝。
- 双耳在 45° 和侧面可辨认，外耳轮不再被头发完全吞没。
- 额头、眉毛和耳朵没有明显黑色发纹污染。
- 正面五官比原导入效果清楚，但没有过度锐化光晕。
- 原版卷发主体轮廓、面部身份感和服装保持不变。
- 导出的 GLB 能被 Blender 5.2 重新导入，材质和贴图不丢失。
- GLB 声明长度与实际长度一致，不包含意外动画。

## 风险与回退

- 原模型的头发、皮肤和耳朵位于同一生成网格中，局部分离可能暴露孔洞。若出现孔洞，只做局部补面，不扩大到全头重拓扑。
- 原贴图中的颜色污染可能跨越 UV 岛。若无法无痕修复，优先保留脸部相似度，并缩小补色范围。
- 若独立眉毛或耳廓补面显得突兀，回退到原几何，仅保留穿模清理和贴图修复。
