# 贴纸探索导航设计

## 目标

把当前 3D 人物脸上的 10 张贴纸改造成个人站的探索式导航。首版启用 6 张贴纸，剩余 4 张作为可响应但未开放的入口。

首页不出现“选择一张贴纸”、操作教程或入口名称。用户通过贴纸的悬停反馈自然发现交互。

## 入口映射

| 贴纸节点 | 状态 | 目标功能区 |
|---|---|---|
| `decal-9` | 已启用 | 个人介绍 |
| `decal-0` | 已启用 | 个人简历 |
| `decal-2` | 已启用 | 项目 A |
| `decal-6` | 已启用 | 项目 B |
| `decal-8` | 已启用 | 项目 C |
| `decal-5` | 已启用 | 联系方式 |
| `decal-1` | 未解锁 | 预留 |
| `decal-3` | 未解锁 | 预留 |
| `decal-4` | 未解锁 | 预留 |
| `decal-7` | 未解锁 | 预留 |

项目 A、B、C 使用明确的示例内容，不虚构真实项目成果。个人资料后续从用户提供的简历读取。

## 交互方案

### 首页探索

- 不显示贴纸教程、功能名称或显式引导文案
- 悬停贴纸时鼠标变为手型
- 贴纸产生轻微发光与小幅翘起，表明它可以点击
- 未悬停时保持人物和贴纸的原始外观

### 已启用贴纸

1. 用户点击贴纸
2. 暂时锁定拖动，避免镜头动画和手势冲突
3. 人物旋转，使目标贴纸朝向镜头
4. 贴纸完成一次短促旋转
5. 镜头推进并揭晓功能区名称
6. 对应内容区进入可阅读状态

整个转场约 0.9 至 1.2 秒，强调沉浸感但不拖慢浏览。

### 未解锁贴纸

1. 人物小幅朝向贴纸
2. 贴纸短促弹动
3. 显示“区域尚未解锁”
4. 约 1.2 秒后提示消失，人物回到原状态

未解锁提示不创建空白页面，也不改变滚动章节。

### 功能区导航

- 功能区顺序固定为：个人介绍、个人简历、项目 A、项目 B、项目 C、联系方式
- 进入任一功能区后，向下滚动进入下一功能区
- 向上滚动返回上一功能区
- 点击返回按钮或按 `Esc` 回到 3D 人物首页
- 回到首页时恢复进入前的正面镜头和拖动能力

## 技术架构

### 贴纸注册表

使用独立数据表管理贴纸，不修改 GLB：

```text
贴纸节点名称
→ 启用状态
→ 功能区标识
→ 功能区标题
→ 镜头聚焦参数
```

以后开放预留入口时只修改注册表和增加内容组件。

### 交互状态机

页面包含五种互斥状态：

- `HUB`：人物首页，可拖动和点击
- `FOCUSING`：镜头聚焦，暂停输入
- `SECTION`：功能区显示，可滚动切换
- `RETURNING`：返回人物首页
- `LOCKED_FEEDBACK`：未解锁反馈

状态机负责阻止重复点击、滚轮连跳和转场过程中误操作。

### 组件边界

- `sticker-registry`：保存贴纸与功能区映射
- `sticker-navigation`：处理 Raycaster 结果与状态跳转
- `camera-transition`：人物旋转、镜头推进和返回动画
- `section-shell`：承载功能区、滚动导航与返回按钮
- `locked-feedback`：显示未解锁提示

当前模型加载、基础灯光和拖动缩放继续复用验收页模块。

## 数据流

1. Raycaster 返回 `decal-*` 节点
2. 导航模块查询贴纸注册表
3. 已启用入口进入 `FOCUSING`
4. 镜头动画完成后进入对应 `SECTION`
5. 滚轮或触摸滑动更新相邻功能区
6. 返回操作进入 `RETURNING`
7. 动画结束后恢复 `HUB`

未启用入口改走 `LOCKED_FEEDBACK`，不会进入内容区。

## 错误与降级

- GLB 中缺少注册贴纸时，该入口自动禁用并记录错误
- 快速连续点击只接受第一次有效操作
- 转场中忽略滚轮与拖动输入
- `prefers-reduced-motion` 开启时缩短转场并取消贴纸旋转
- 移动端使用点击和纵向滑动，不依赖鼠标悬停
- WebGL 失败时保留现有错误界面，不显示不可用入口

## 验收标准

- 首页没有“选择贴纸”或其他显式操作教程
- 10 张贴纸均有清晰悬停或点击反馈
- 6 张启用贴纸可正确进入各自功能区
- 4 张预留贴纸显示“区域尚未解锁”并自动恢复
- 转场期间不能重复触发入口
- 功能区可按固定顺序上下切换
- 返回按钮与 `Esc` 均能回到人物首页
- 移动端点击和滑动有效
- 降低动态效果设置下仍能完成所有导航

## 明确排除

- 在线贴纸编辑器
- 用户自行更换贴纸或功能映射
- 后台管理系统
- 真实项目内容补全
- 部署与公开发布
