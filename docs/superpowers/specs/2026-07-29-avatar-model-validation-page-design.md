# 3D 人物模型验收页设计

## 目标

建立一个独立的本地网页，用于验证 `Untitled-project.glb` 能否作为个人站首页核心资产。用户应能在浏览器中看到完整人物、拖动旋转、滚轮缩放，并逐一验证 10 张贴纸的悬停和点击。

本阶段只验证模型与交互底座，不制作正式首页或任何内容功能区。

## 已确认的模型结构

- GLB 2.0，文件大小约 6.56 MB
- 1 个主人物网格，10 个独立贴纸节点：`decal-0` 至 `decal-9`
- 13 张内嵌纹理，其中人物使用基础色、法线、金属粗糙度贴图
- 场景约 15.2 万渲染顶点
- 无人物骨骼动画
- 内含一段 4 秒相机动画 `CameraAction`，验收页不播放
- 内含 `focus-0`、`focus-1` 两个辅助定位节点

## 方案比较

### A. Vite + 原生 JavaScript + Three.js（采用）

依赖少、启动快，Three.js 行为完全可控，并可直接演进为正式个人站。适合当前尚无网页工程的空仓库。

### B. 单 HTML + CDN Three.js

文件最少，但依赖远程 CDN、模块路径脆弱，后续增加动画和内容区时需要重构。

### C. React + React Three Fiber

适合复杂组件化项目，但首个验收页会引入不必要的框架层和学习成本。

## 页面构成

### 3D 画布

- 全屏显示人物胸像
- 使用暖灰白背景，避免暗色背景吞掉黑色头发和贴纸边缘
- 摄像机自动根据模型包围盒定位
- 使用环境光、柔和主光和轮廓补光检查 PBR 材质

### 状态面板

- 显示模型加载状态与加载失败信息
- 显示当前悬停或点击的贴纸编号
- 显示简短操作提示：拖动旋转、滚轮缩放、点击贴纸
- 提供“恢复正面”按钮

## 交互

### 模型旋转

- 鼠标或触摸拖动人物时旋转模型根节点
- 水平方向为主要旋转，垂直方向只允许小幅变化
- 松手后保留轻微惯性，但不会持续自动旋转

### 缩放

- 鼠标滚轮或触控双指调整相机距离
- 限制最近和最远距离，避免进入模型内部或模型消失

### 贴纸识别

- 使用 Three.js Raycaster 仅检测 `decal-*` 节点
- 悬停时改变鼠标样式，并对贴纸增加轻微亮度反馈
- 点击后在状态面板显示贴纸编号
- 不在本阶段跳转功能区，也不改写贴纸材质资源

## 文件与模块规划

```text
个人站/
├─ index.html
├─ package.json
├─ public/
│  └─ models/
│     └─ xiaoyuan-avatar.glb
└─ src/
   ├─ main.js
   ├─ style.css
   └─ three/
      ├─ create-scene.js
      ├─ load-avatar.js
      └─ avatar-interaction.js
```

- 原始下载文件保持不变
- 实施时复制到 `public/models/xiaoyuan-avatar.glb`
- 场景创建、模型加载和交互逻辑分离，方便后续正式首页复用

## 数据流

1. 页面启动并创建 Three.js 场景
2. GLTFLoader 加载模型
3. 根据包围盒居中人物并定位相机
4. 遍历场景收集 `decal-*` 节点
5. 指针移动时 Raycaster 检测悬停贴纸
6. 点击贴纸后更新状态面板
7. 拖动、滚轮和触摸事件更新模型旋转或相机距离

## 错误与降级

- 加载失败时显示明确错误，不保留空白画布
- 未发现 10 个贴纸时显示实际识别数量
- 限制设备像素比，降低移动端 GPU 压力
- 浏览器不支持 WebGL 时显示静态提示
- 透明贴纸若出现排序或闪烁，优先调整 `depthWrite` 与渲染顺序，不修改原 GLB

## 验收标准

- 本地命令可稳定启动页面
- 人物、肤色、头发、服装和全部贴纸显示正常
- 页面识别到 10 个独立贴纸
- 鼠标和触摸拖动均可旋转人物
- 滚轮缩放不会穿入模型
- 每张贴纸均可产生悬停反馈并显示正确编号
- “恢复正面”按钮有效
- 桌面和移动尺寸下布局不遮挡人物关键区域
- 控制台无阻塞性错误

## 明确排除

- 正式首页标题和导航
- 个人介绍、简历、项目 A/B/C、联系方式
- 点击贴纸后的镜头转场和内容功能区
- 页面滚动章节、音效、后期特效和部署
- GLB 几何、贴纸内容或贴图的重新编辑
