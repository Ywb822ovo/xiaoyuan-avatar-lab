# 全站鼠尾草胶片背景设计规格

## 1. 已批准方向

全站采用“参考式改造”背景：以鼠尾草绿为主色，人物背后保持暖米色中心光，四周加入轻微橄榄灰暗角，并叠加明显但克制的旧胶片颗粒。

本设计只借鉴参考网站的色彩与胶片氛围，不复制其背景图片、纹理资源或其他素材。人物、贴纸、排版、章节结构和镜头路径保持不变。

## 2. 色彩系统

| 用途 | 色值 |
|---|---|
| WebGL 基础底色 | `#A8AE8E` |
| 鼠尾草主色 | `#9FA889` |
| 暖米色中心光 | `#DDD2AE` |
| 橄榄灰暗角 | `#5F6651` |
| 浅色正文表面 | `rgba(232, 229, 207, 0.82)` |
| 主文字 | `#17201D` |
| 次要文字 | `#4F594F` |
| 交互信号橙 | `#FF6B3E` |

人物正后方亮度最高，保证深色头发与脸部轮廓清晰；页面边缘逐渐转为低饱和鼠尾草绿，不使用纯黑暗角。

## 3. 背景层级

背景由可响应的程序化层组成，不使用整张生成图：

1. Three.js 场景底色：统一灰鼠尾草绿，避免模型边缘露出旧象牙白。
2. 中心光晕：暖米色径向渐变，中心跟随人物主要构图区域。
3. 鼠尾草渐变：覆盖全屏的低饱和绿色过渡。
4. 暗角：只压低边缘亮度，不遮黑正文。
5. 胶片颗粒：保留现有程序化噪点，适度提高可见度。
6. 旧纸斑点：加入极淡、不规则的静态尘点，禁止出现大面积污渍。

## 4. 滚动变化

- 首屏：中心光最明亮，颜色偏暖，突出人物和贴纸。
- 关于与简历：鼠尾草绿略加深，保持纸张般的阅读感。
- 项目 A/B/C：中心光略收窄，边缘暗角增强约一档，制造镜头感。
- 联系方式：背景重新变暖、变平静，形成收束。

变化只通过 CSS 自定义属性和当前章节状态完成。颜色连续插值，不闪烁、不硬切，也不增加新的 WebGL 后处理依赖。

## 5. UI 适配

- 胶片栏改为半透明鼠尾草灰表面，保持深色激活项和橙色进度线。
- 内容卡片改为暖灰绿色半透明纸张，不使用纯白。
- 页面边框和刻度使用深橄榄灰，维持当前视觉层级。
- 黑色标题保持不变；背景最暗状态仍需达到清晰可读的对比度。
- 人物肤色、蓝色牛仔服和贴纸材质不主动染色；仅环境光允许出现非常轻的暖绿反射。

## 6. 动效与性能

- 胶片颗粒继续使用内嵌 SVG 噪点，不下载外部纹理。
- 颗粒移动幅度小于当前画面的 2%，避免抖动抢眼。
- `prefers-reduced-motion` 下颗粒保持静止，滚动颜色变化仍可用。
- 移动端降低颗粒透明度与暗角强度，防止小屏显脏。
- 不增加新的 JavaScript 动画循环；章节变化复用现有滚动状态。

## 7. 验收标准

- 全站从首屏到联系方式都使用鼠尾草绿背景体系。
- 人物背后存在清晰但柔和的暖米色中心光。
- 页面边缘有轻微暗角，但没有纯黑或明显脏污块。
- 胶片颗粒肉眼可感知，但不影响文字和贴纸辨识。
- 滚动到不同章节时背景明暗连续变化。
- 胶片栏、卡片和边框与新背景协调，橙色交互信号保留。
- 1440×900 和 390×844 下标题、正文与导航对比度清晰。
- 减少动态模式下没有移动颗粒。
- 不新增外部图片、字体或运行时依赖。
- 不修改人物模型、贴纸、镜头路径或个人内容。
- `npm run build` 通过，浏览器控制台无新增错误。
