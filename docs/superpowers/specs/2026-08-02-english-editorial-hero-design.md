# 英文编辑式首页排版设计规格

## 1. 已批准方向

首页采用 A「编辑杂志感」全英文排版。文案不是对“小缘的个人空间”的逐句翻译，而是围绕 3D 人物、贴纸探索和滚动交互重新创作。

本次只改首屏可见文字及胶片栏标签。向下滚动后的个人介绍、简历、项目和联系方式正文继续保留中文，不翻译、不扩写，也不虚构用户资料。

## 2. 最终文案

### 顶部索引

```text
XIAOYUAN / PERSONAL INDEX / 2026
```

### 主标题

```text
ME, IN
THREE
DIMENSIONS.
```

### 说明文字

```text
A face full of clues.
Drag to look closer. Scroll to know the rest.
```

### 操作提示

```text
DRAG TO LOOK · SCROLL TO KNOW
```

### 背景装饰字

```text
LIVING PORTRAIT
```

### 胶片栏

```text
ABOUT / RÉSUMÉ / PROJECT A / PROJECT B / PROJECT C / CONTACT
```

## 3. 文字层级

主标题使用三层字体性格，而不是三行相同的粗体：

- `ME, IN`：小号大写无衬线体，承担引子
- `THREE`：最大字号的斜体衬线体，是首屏唯一文字视觉焦点
- `DIMENSIONS.`：粗体无衬线体，宽度略小于 `THREE`，承担结论

桌面端建议视觉比例：

| 元素 | 建议字号 | 特征 |
|---|---:|---|
| 顶部索引 | 9–10px | 等宽、大字距、橙色起始词 |
| `ME, IN` | 22–28px | 中等字重、大字距 |
| `THREE` | 104–132px | Georgia 类衬线斜体、紧凑行高 |
| `DIMENSIONS.` | 58–74px | 粗黑无衬线、小幅负字距 |
| 说明文字 | 13–15px | 两行、较宽行距 |
| 操作提示 | 9px | 等宽、大字距 |

## 4. 构图

- 文字组位于左侧安全区，宽度约 410–470px
- 人物桌面端略向右偏移，使标题和头发之间至少保留 28px 视觉间距
- 主标题垂直中心略高于人物眼睛，避免与胶片栏挤在同一高度
- `LIVING PORTRAIT` 位于右上背景层，透明度约 7%–11%，不能与人物眼睛争抢焦点
- 操作提示移出人物胸口，放在左下文字区末端或胶片栏上方
- 页面第一眼顺序固定为：人物眼睛 → `THREE` → `DIMENSIONS.` → 说明文字 → 胶片栏

## 5. 胶片栏英文适配

- 标签全部使用大写英文
- `RÉSUMÉ` 保留重音符号
- `PROJECT A/B/C` 保持示例性质，不增加虚构项目名称
- 标签字号控制在 10–11px，等宽或中性无衬线体
- 六个入口宽度保持稳定，不因英文长度导致页面溢出
- 激活态继续使用深色底和橙色信号点

## 6. 中英边界

- 首屏与固定胶片栏：英文
- 滚动后的章节标题、说明与卡片：中文
- 状态文字 `EXPLORE`、`DIRECTED / SCROLL`：继续使用英文
- 加载错误等功能提示：继续使用中文，保证用户能够理解

这种边界让首屏具有国际化海报感，同时避免把尚未整理的个人内容强行翻译成英文。

## 7. 响应式

### 桌面端

- 主标题完整显示三层结构
- `THREE` 最大，但不越过人物面部安全区
- 说明文字保持两行

### 手机端

- 主标题缩为 `ME, IN / THREE / DIMENSIONS.` 三行，整体宽度不超过 250px
- `THREE` 约 58–68px，`DIMENSIONS.` 约 28–34px
- 人物向下移动出标题安全区，标题不得压住眼睛、眉毛或主要贴纸
- 背景装饰字可隐藏，避免与人物和标题重叠
- 操作说明缩成 `DRAG · SCROLL`
- 胶片栏继续横向滚动，页面本身不得横向溢出

## 8. 动效

- 首页加载完成后，顶部索引、三层主标题和说明文字依次淡入
- `THREE` 可比其他标题晚约 80–120ms，形成主视觉落点
- 动画只使用透明度和 10–18px 位移，不拆字、不做逐字跳动
- `prefers-reduced-motion` 下取消依次进入，所有文字直接显示
- 滚动进入故事后，首页文字平滑淡出，不覆盖章节正文

## 9. 明确排除

- 不把中文章节正文翻译成英文
- 不虚构英文职业头衔、个人宣言、项目成果或联系方式
- 不增加新的页面、弹窗或导航结构
- 不修改 3D 模型、贴纸、镜头路径或鼠尾草胶片背景方向
- 不使用难以核实授权的网络字体；首版使用系统字体与通用衬线字体组合

## 10. 验收标准

- 首屏不再出现“小缘的个人空间”“LOOK / DISCOVER”或旧中文操作说明
- 主标题准确显示 `ME, IN / THREE / DIMENSIONS.`
- `THREE` 是最突出的文字元素，但不遮挡人物脸部
- 说明文字和操作提示使用批准的英文文案
- 胶片栏六个标签全部为批准的英文标签
- 向下滚动后的详细章节正文仍为中文
- 桌面端标题、人物和胶片栏不存在明显遮挡或视觉争抢
- 390px 宽手机端标题不遮挡眼睛、眉毛和主要贴纸
- 页面无横向溢出，胶片栏仍可定位全部章节
- 减少动态模式下文字完整可见
- `npm run build` 通过，浏览器控制台无新增错误
