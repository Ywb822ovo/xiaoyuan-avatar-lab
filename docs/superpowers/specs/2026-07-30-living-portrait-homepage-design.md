# 「Living Portrait」首页重设计规格

## 1. 设计状态

本规格替代 `2026-07-29-sticker-navigation-design.md` 中“点击贴纸后打开独立功能区遮罩、滚动切换章节”的交互方案。

用户已经批准：

- 首页采用浅色 `Soft Index` 视觉方向
- 使用 C「胶片式底栏」承载内容
- 3D 人物始终留在首页，不跳转、不消失、不被全屏内容层覆盖
- 点击贴纸只改变人物／镜头视角并切换底栏内容
- 当前 GLB 不重建眼球，首版使用人物小幅跟随鼠标模拟注视

视觉基准：

- `assets/design/homepage-soft-index.png`
- `docs/visual-direction/soft-index-philosophy.md`

## 2. 目标

把当前“3D 导航页 + 独立章节遮罩”改为一个始终围绕人物展开的沉浸式单页首页。

访问者进入页面后先看到人物和贴纸。点击任意已启用贴纸时，人物平滑转向对应视角，贴纸完成一次短促反馈，底部胶片栏在同一个页面内更新内容。浏览过程不出现整页跳转、模糊背景遮罩或“返回首页”步骤。

## 3. 明确排除

- 不重建或切割 GLB 眼球
- 不把贴纸点击改成新页面、路由或全屏弹层
- 不继续使用上下滚动切换独立章节
- 不加入后台、在线贴纸编辑器或新的模型制作能力
- 不虚构用户经历、项目成果、邮箱或社交账号
- 不开放四个预留贴纸的正式内容

## 4. 视觉系统

### 4.1 色彩

| 用途 | 色值 |
|---|---|
| 主背景 / Mineral Ivory | `#EEE9DE` |
| 主文字 / Ink | `#17201D` |
| 辅助色 / Celadon | `#CCD8CD` |
| 模型服装呼应 / Oxidized Blue | `#31537A` |
| 激活与注视标记 / Tangerine | `#FF6B3E` |

页面保持明亮，不使用暗黑色大面积背景。颜色以低饱和底色和单一橙色激活信号为主。

### 4.2 字体与层级

- 英文展示字：`Instrument Sans`
- 坐标、索引和状态字：`DM Mono`
- 中文回退：`Microsoft YaHei UI`, `PingFang SC`, sans-serif
- 字体文件使用 OFL 许可版本，随站点本地加载并保留许可证
- 首页标题“**小缘的个人空间**”改为顶部左侧的小型身份标识，不再使用占据左半屏的黑色大标题
- 大号英文 `LOOK / DISCOVER` 只作为视觉锚点，不承载必读信息

### 4.3 空间结构

桌面端由四层组成：

1. 全屏 Three.js 画布和常驻人物
2. 顶部身份栏：站点标题、交互状态和简短操作标识
3. 左侧低密度视觉文字：`LOOK / DISCOVER` 与一句解释
4. 底部固定胶片栏：当前内容和其余入口

人物保持视觉中心，任何 UI 都不得覆盖眼睛、鼻子或主要贴纸区域。

## 5. 胶片式底栏

### 5.1 内容映射

| 顺序 | 贴纸 | 内容 |
|---|---|---|
| 01 | `decal-9` | 关于我 |
| 02 | `decal-0` | 个人履历 |
| 03 | `decal-2` | 项目 A |
| 04 | `decal-6` | 项目 B |
| 05 | `decal-8` | 项目 C |
| 06 | `decal-5` | 联系我 |

`decal-1`、`decal-3`、`decal-4`、`decal-7` 继续作为预留贴纸，但不出现在正式底栏入口中。

### 5.2 显示规则

- 默认状态展示六个紧凑入口
- 激活项扩大，显示标题和一段短说明；其他项保持索引与标题
- 点击底栏入口与点击对应贴纸产生完全相同的视角切换
- 切换内容时只更新底栏，不创建新页面或大面积内容容器
- `Esc` 或点击当前激活项，可返回正面中立视角并收起详细说明
- 项目 A、B、C 明确标记为示例内容
- 缺失的个人信息继续使用“待补充／待整理”，不得自动编造

## 6. 人物与贴纸交互

### 6.1 鼠标跟随

当前 GLB 只有一个人物主网格、十个贴纸网格，没有独立眼球、骨骼或 Morph Target。因此首版不实现真正的眼珠旋转。

采用“活体肖像”模拟：

- 鼠标在画布内移动时，人物在当前基础视角上附加小幅偏转
- 水平最大约 `±3°`，垂直最大约 `±1.5°`
- 使用阻尼插值，避免人物机械地紧贴光标
- 鼠标离开画布后缓慢回到基础视角
- 拖拽、双指缩放、贴纸聚焦动画进行时，跟随偏移归零并暂停
- 聚焦动画结束约 250ms 后恢复跟随
- `prefers-reduced-motion` 下关闭鼠标跟随

实现时必须把“用户拖拽／贴纸聚焦产生的基础旋转”和“鼠标跟随偏移”分开保存，最终渲染旋转为两者之和，防止状态互相覆盖。

### 6.2 已启用贴纸

1. 悬停时显示轻微橙色发光和手型鼠标
2. 点击后进入 `FOCUSING`
3. 暂停拖拽和鼠标跟随
4. 人物／镜头在 700–900ms 内平滑转到该贴纸的预设视角
5. 贴纸完成一次短促旋转反馈
6. 底栏激活对应入口并更新短内容
7. 进入 `FOCUSED`，恢复拖拽和轻微鼠标跟随

点击另一个贴纸或底栏入口时，直接从当前视角过渡到新视角，不先回正面。

### 6.3 预留贴纸

- 人物只做小幅朝向
- 贴纸短促弹动
- 显示小型提示“区域尚未开放”
- 不改变底栏激活项，不创建空内容
- 约 1.2 秒后提示消失，回到操作前视角

## 7. 状态机

旧状态 `HUB / SECTION / RETURNING` 改为：

- `EXPLORE`：正面或自由拖拽状态
- `FOCUSING`：贴纸或底栏触发的视角过渡，暂时锁定输入
- `FOCUSED`：某个内容已激活，人物和底栏同时保留
- `LOCKED_FEEDBACK`：预留贴纸反馈

状态规则：

- `FOCUSING` 期间忽略重复点击、滚轮和拖拽
- `FOCUSED` 允许直接选择其他入口
- `Esc` 从 `FOCUSED` 返回 `EXPLORE`
- 快速连续选择只执行最后一次被状态机接受的操作

## 8. 组件调整

### 保留并扩展

- `sticker-registry`：继续维护贴纸与内容映射
- `avatar-interaction`：增加基础旋转与鼠标跟随偏移分层
- `sections`：继续作为真实内容和 ABC 示例内容的数据源
- `locked-feedback`：改成与新视觉系统一致的小型提示

### 替换

- `section-shell` 替换为 `film-dock`
- `sticker-navigation` 移除打开、关闭整页功能区的逻辑，改为同步视角与底栏
- 旧的大型模糊遮罩、返回按钮和章节滚动逻辑全部删除

### 数据流

```text
贴纸点击 / 底栏点击
→ sticker-registry 查询目标内容
→ navigation 状态进入 FOCUSING
→ avatar-interaction 更新基础视角
→ film-dock 更新 activeSectionId
→ 动画结束进入 FOCUSED
→ 恢复拖拽与轻微鼠标跟随
```

## 9. 响应式与降级

### 移动端

- 不启用鼠标跟随
- 保留单指拖拽和双指缩放
- 胶片栏改为横向滚动，激活项宽度大于普通项
- 页面不依赖 hover 才能发现入口
- 顶部说明精简，避免遮挡人物头部

### 减少动态效果

- 视角切换缩短为约 150–220ms
- 取消贴纸完整旋转，只保留轻微缩放
- 关闭人物鼠标跟随和惯性
- 内容切换仍然完整可用

### WebGL 失败

保留现有模型加载错误状态；胶片栏不显示成可操作入口，避免产生点击后无响应的假界面。

## 10. 验收标准

- 首屏视觉与批准的 `homepage-soft-index.png` 保持同一配色、层级和空间逻辑
- 页面标题为“小缘的个人空间”，位置不遮挡人物
- 3D 人物在所有内容状态下始终可见
- 点击六个启用贴纸不会跳转页面或打开全屏遮罩
- 六个贴纸分别激活正确底栏内容和视角
- 点击底栏六个入口可反向定位对应贴纸视角
- 切换两个入口时不必先返回正面
- 鼠标移动产生克制、平滑的小幅人物跟随
- 拖拽和聚焦动画不与鼠标跟随打架
- 四个预留贴纸只显示未开放反馈
- `Esc` 能返回中立视角
- 项目 A、B、C 仍明确为示例，不出现虚构成果
- 320px 宽移动端能够拖拽人物并横向浏览底栏
- `prefers-reduced-motion` 下所有入口仍可完成操作
- 构建命令通过，浏览器控制台无新增错误
