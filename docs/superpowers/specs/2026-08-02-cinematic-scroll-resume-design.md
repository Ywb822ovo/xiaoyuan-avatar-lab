# 3D 个人站连续镜头叙事升级规格

## 1. 设计状态

本规格是 `2026-07-30-living-portrait-homepage-design.md` 的增量升级。用户已批准借鉴 `dayinji/sen-3d-resume` 的连续镜头与视觉节奏，但不复制其模型、履历、品牌、图片或文字。

最终交互原则已经确认：

- 首页 3D 人物保持不变，贴纸只切换人物视角和首页预览
- 页面向下滚动后，按照固定顺序进入连续叙事章节
- 底部胶片栏显示进度，并可平滑定位到任意章节
- 全程不跳转新页面，不打开全屏项目弹窗
- 人物从首屏到联系方式始终存在于同一个 Three.js 场景

## 2. 目标与范围

把现有单屏贴纸导航升级为一个明亮、沉浸、可连续滚动的 3D 个人站：访问者先自由观察人物，再通过滚动进入“关于我 → 个人履历 → 项目 A → 项目 B → 项目 C → 联系方式”。每个章节对应一个明确的镜头构图和文字布局。

首版继续使用现有用户 GLB、现有贴纸映射和 ABC 示例项目，不虚构个人经历、项目结果、邮箱、社交账号或作品图片。

## 3. 明确排除

- 不迁移到 React 或 React Three Fiber
- 不复制参考站的模型、贴纸、履历、品牌、图像、视频或文案
- 不依赖参考 GLB 的 `CameraAction`、`focus-*` 或眼球节点
- 不实现真正的眼球旋转；当前 GLB 没有独立眼球网格
- 不加入新页面、路由、大型详情弹窗或复杂后台
- 不加入在线 AI 生模、在线贴纸编辑器或可视化动画时间轴
- 不在本轮补充真实项目素材或联系方式

## 4. 体验结构

### 4.1 首屏：自由探索模式

- 首屏占一整个视口，沿用批准的浅色 `Soft Index` 视觉系统
- 人物居中偏右，标题“小缘的个人空间”位于左上安全区
- 用户可以拖拽人物、滚轮缩放，并获得克制的鼠标跟随效果
- 点击六个已启用贴纸只让人物平滑转到对应预览角度，同时更新胶片栏的预览状态
- 点击预留贴纸只显示“区域尚未开放”，不改变当前章节
- 首屏贴纸点击不滚动页面、不打开内容层

### 4.2 导演滚动模式

页面离开首屏后，滚动接管人物与镜头：

1. 关于我：中近景正面，文字位于左侧
2. 个人履历：脸部近景或三分之二侧面，时间线位于右侧
3. 项目 A：左侧人物局部，右侧项目卡片
4. 项目 B：镜头切换至另一侧，保持节奏变化
5. 项目 C：较远景，给项目信息更大阅读空间
6. 联系方式：人物回到较平静的正面构图，显示待补充联系方式

章节之间不硬切。滚动进度通过插值同时驱动人物旋转、镜头距离、镜头注视高度、人物水平偏移和文字显隐，形成连续镜头。

### 4.3 回到首屏

- 滚动回首屏顶部后恢复自由拖拽、缩放和鼠标跟随
- 从导演模式返回时，人物平滑回到用户最后一次首页预览视角
- 模式切换期间短暂锁定拖拽，避免输入争抢

## 5. 胶片栏

胶片栏固定在视口底部，是同一个组件的两种状态：

- 首屏：显示六个入口；贴纸点击只改变其预览激活态
- 内容区：显示当前章节进度；点击任一入口平滑滚动到对应章节

胶片栏顺序固定为：关于我、个人履历、项目 A、项目 B、项目 C、联系方式。项目 A/B/C 必须明确标注为示例。

点击胶片栏允许跨章节定位，但必须通过浏览器平滑滚动经过同一条连续镜头路径，不直接跳变 3D 状态。开启减少动态效果时改为短时滚动，并取消夸张过渡。

## 6. 技术架构

保持现有 Vite + 原生 JavaScript + Three.js 架构。

### 6.1 页面层

- `index.html`：从单屏舞台改为固定 3D 舞台加滚动章节轨道
- `sections.js`：继续作为全部文字内容的唯一数据源
- 新的 `cinematic-scroll`：计算章节边界、总滚动进度和活跃章节
- 新的 `film-dock`：负责预览激活、章节激活和点击定位
- 章节 DOM：只负责排版、可访问性和内容显隐，不直接修改 Three.js

### 6.2 3D 层

`avatar-interaction` 将人物姿态拆成三层：

1. 首页基础姿态：拖拽或贴纸预览产生
2. 滚动导演姿态：由相邻镜头预设插值得到
3. 活体偏移：鼠标跟随产生的小幅附加旋转

最终每帧根据当前模式合成姿态。导演模式拥有最高控制权；活体偏移在内容区显著减弱或关闭。

由于现有模型没有参考站的摄像机动画，本项目使用代码定义的镜头预设。预设只包含数值参数，不修改 GLB。

### 6.3 状态机

- `EXPLORE`：首屏自由拖拽和贴纸预览
- `ENTERING_STORY`：首屏进入内容区的短过渡
- `STORY`：滚动控制镜头和章节
- `SEEKING`：胶片栏触发平滑定位
- `LOCKED_FEEDBACK`：预留贴纸反馈

滚动和拖拽不同时控制同一层姿态。页面顶部阈值和迟滞区防止状态在边界来回闪烁。

## 7. 视觉与动效

- 延续矿物象牙白、鼠尾草绿、氧化蓝与橙色激活点，不使用暗黑主背景
- 增加非常轻的颗粒纹理和边框刻度，但保证文字清晰
- 用非对称的大比例脸部裁切制造视觉冲击，不把所有章节都做成居中证件照
- 文字每章最多一个标题、一段摘要和两至三条信息，避免 3D 与文案争抢
- 章节进入和退出采用透明度、位移与轻微模糊，不使用大面积毛玻璃遮罩
- 动画采用阻尼/缓动，快速滚动时追随目标进度，不排队播放过期动画

## 8. 响应式与降级

### 桌面端

- 项目 A/B/C 可使用固定视口中的横向卡片组合，但页面本身不得产生横向滚动条
- 人物在每章至少保留约三分之一可见面积

### 移动端

- 关闭鼠标跟随，保留首屏单指拖拽
- 章节使用纵向卡片，不做桌面式横向固定轨道
- 人物成为上半屏或低对比背景，文字保持独立可读区域
- 胶片栏允许横向滚动，但页面宽度不得溢出

### 减少动态与 WebGL 失败

- `prefers-reduced-motion` 下缩短镜头插值、关闭颗粒漂移和贴纸完整旋转
- WebGL 失败时仍显示所有章节文字与胶片栏，3D 入口显示不可用状态

## 9. 数据流

```text
滚动位置 / 胶片栏点击
→ cinematic-scroll 计算 storyProgress 与 activeSection
→ avatar-interaction 插值相邻镜头预设
→ section DOM 更新显隐和可访问状态
→ film-dock 同步当前章节

首页贴纸点击
→ sticker-registry 查询入口
→ avatar-interaction 更新首页预览姿态
→ film-dock 更新 previewSection
→ 页面保持在首屏
```

## 10. 错误处理

- GLB 或贴纸缺失：记录明确错误，禁用相应贴纸，但正文仍可滚动阅读
- 快速滚动：以最新滚动位置为唯一真值，不堆积转场任务
- 平滑定位被用户滚轮或触摸中断：立即退出 `SEEKING`，交还原生滚动控制
- 页面尺寸变化：重新测量章节边界，并保留当前章节而不是跳回顶部
- 模型性能不足：降低像素比并关闭次要视觉效果，不删除正文

## 11. 验收标准

- 首屏视觉继续符合已批准的浅色 `Soft Index` 方向
- 点击六个已启用贴纸只切换预览视角，不滚动、不弹窗、不跳页
- 页面滚动顺序固定为六个已确认章节
- 每个章节都有可辨识且连续的 3D 构图变化
- 快速上下滚动后，人物、胶片栏和文字仍指向同一章节
- 胶片栏可从任意位置平滑定位到六个章节
- 回到页面顶部后恢复首屏拖拽和鼠标跟随
- 人物在所有章节持续可见，不被整页内容覆盖
- 项目 A/B/C 明确显示为示例内容
- 不出现虚构个人资料或联系方式
- 390px 宽移动端无横向页面溢出，正文可读
- 开启减少动态效果后所有导航仍可使用
- GLB 加载失败时正文仍可访问
- `npm run build` 通过，浏览器控制台无新增错误
