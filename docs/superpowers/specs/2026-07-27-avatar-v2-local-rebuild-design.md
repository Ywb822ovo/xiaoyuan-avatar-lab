# 小缘 3D 头像 V2 局部重建设计

日期：2026-07-27

状态：已确认设计，等待书面规格复核

实施工具：Blender；用户指定通过 `computer-use` 插件进行交互式建模

## 1. 目标

在不破坏现有最终模型的前提下，制作一个适合上传 Intro3D 的 V2 GLB。V2 保留现有牛仔外套、白色内搭、半身构图、卡通化五官和蓬松卷发方向，重点解决：

1. 发际线与额头粘连、尖刺、破面和穿插。
2. 细碎卷发互相融合，缺乏清晰发束。
3. 侧脸中面部向前鼓起。
4. 下颌角、下颌线和下巴转折不明显。

目标输出为：

`C:\Users\wbbb\Documents\个人站\xiaoyuan-avatar-intro3d-v2.glb`

旧版 `avatar-final.glb` 和 `xiaoyuan-avatar-intro3d.glb` 必须保留，不覆盖、不删除。

## 2. 已确认的造型方向

### 2.1 脸部

- 保留长脸、浓眉、大眼、挺鼻和略酷的神态。
- 收平中面部与脸颊，消除目前侧面轮廓的整体前凸感。
- 下颌两侧形成连续、清晰但不过分锋利的直线。
- 下颌角在正面和 45° 视角可识别。
- 下巴略向前，底部偏方圆，不做尖锥形。
- 保持动画角色比例，不追求真人扫描精度。

### 2.2 头发

采用用户确认的 B 方案：

- 保留蓬松、凌乱、外翻的卷发轮廓。
- 重建为约 12–16 束主要卷发，并用少量辅助发束补足轮廓。
- 每束头发具有清楚的根部、主体和收尖方向。
- 新建独立头皮底层，避免发束间露出空洞。
- 刘海不穿入额头、眉毛或眼睛。
- 侧发不穿入耳朵或脸颊。
- 清除发际线附近所有细小尖刺、悬浮碎片和融化状表面。

## 3. 技术路径

采用“保留躯干 + 重建头脸轮廓与头发”的局部重建。

### 3.1 保留部分

- 牛仔外套、白色内搭和胸像裁切。
- 现有基础色方向和整体人物比例。
- 已验证可被 GLB 2.0 正常加载的场景尺度与朝向。

### 3.2 重建部分

- 在 Blender 中复制现有最终工程为 V2 工作文件。
- 对头部区域进行受控雕刻或顶点调整，修正脸颊深度、下颌角和下巴。
- 移除或压平发际线破损区域，恢复连续额头表面。
- 建立独立头皮底层。
- 使用曲线或低多边形发束建立 12–16 束主要卷发；确认形状后转换为网格。
- 对发束进行法线、平滑和穿插检查。

### 3.3 导出结构

Blender 工作文件中允许头部、头皮、头发与躯干保持独立对象，以便修改。导出前将可见几何组织为一个 GLB 场景；允许多个不相交网格节点，但不使用骨骼、动画、毛发粒子、几何节点运行时依赖或特殊压缩扩展。

材质以网页兼容为优先：

- PBR 基础材质。
- 纹理嵌入 GLB。
- 保持非金属、偏哑光的卡通表面。
- 不依赖仅 Blender 可见的程序化节点效果。

## 4. 实施流程

1. 复制 `avatar-final.blend` 为 V2 工作文件。
2. 在 Blender 中建立正面、45°、侧面和发际线近景检查视图。
3. 先修脸部轮廓，在无头发遮挡状态下验证下颌与中面部。
4. 再建立头皮和主要发束，逐束检查穿插。
5. 恢复并校正材质。
6. 输出 V2 检查图。
7. 导出 GLB。
8. 将 GLB 重新导入一个空 Blender 场景，检查外观和结构是否保持一致。
9. 进行 GLB 文件头、长度、网格、材质、纹理和扩展检查。

## 5. 验收标准

### 5.1 几何外观

- 正面、45° 和侧面均不出现额头尖刺或破面。
- 刘海与额头之间存在可见、稳定的边界。
- 头发主体不再呈现大量融化、粘连的细碎泥条。
- 耳朵、眼睛、眉毛和脸颊不被头发穿透。
- 侧面脸颊不再整体向前鼓。
- 正面和 45° 可看出更清晰的下颌线。
- 侧面可看出下颌角到下巴的明确转折。
- 脖子与服装连接处无新增破洞。

### 5.2 文件结构

- 文件为有效 GLB 2.0。
- 声明长度与实际文件长度一致。
- 至少包含一个场景、一个网格和一个材质。
- 基础色纹理嵌入文件。
- 不使用 Draco、Meshopt 或平台兼容性未核实的扩展。
- 导出后重新导入 Blender 不丢失模型、材质或纹理。

### 5.3 交付物

- `xiaoyuan-avatar-intro3d-v2.glb`
- `assets/avatar/blender/avatar-v2-local-rebuild.blend`
- 正面、45°、侧面和发际线近景检查图
- V2 文件大小、网格数量、三角面数量、材质数量、纹理数量与 SHA-256

## 6. 风险与处理

### 6.1 旧纹理在修改后的脸部拉伸

处理：优先保持 UV 连续；若局部拉伸明显，仅重投射或重绘受影响的脸部区域，不改动已正常的服装纹理。

### 6.2 新发束显得过于塑料

处理：使用哑光材质、较宽的高光和轻微粗糙度变化；不使用透明发丝卡片。

### 6.3 发量减少后轮廓不够蓬松

处理：优先调整主要发束的体积和方向，而不是重新加入大量细碎发丝。

### 6.4 Intro3D 对复杂 GLB 的未公开限制

官方公开页面确认可上传自有 GLB，但未公开文件大小和多网格限制。V2 因此保持普通 GLB 2.0、嵌入纹理、不使用特殊扩展，并控制在适合网页传输的体量。最终仍需以用户账号中的实际上传结果作为平台兼容性的最终验证。

## 7. 明确排除

- 不制作骨骼、表情形变、眨眼、口型或身体动画。
- 不在这一阶段加入贴纸。
- 不重做服装款式。
- 不加入全身、手臂或腿。
- 不承诺专业角色美术逐点手雕或电影级拓扑。
- 不覆盖或删除任何现有模型、纹理、预览图或 Blender 工程。
